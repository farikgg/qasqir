# 🐺 Qasqir AI — Интеллектуальный WhatsApp-ассистент

Qasqir AI — это умный виртуальный помощник для сети электрозарядных станций (ЭЗС) Qasqir.kz в Казахстане. Бот работает в WhatsApp, общается естественным языком на русском и казахском, помогает водителям находить станции, решать проблемы с зарядкой и оплатой, а также распознает голосовые сообщения.

## ✨ Ключевые возможности
*   **Гибридная память (RAG):** Бот ищет нужные станции и технические инструкции в локальной векторной базе данных (PostgreSQL + `pgvector`), не перегружая контекст LLM.
*   **Мультимодальность:** Понимает как текстовые, так и **голосовые сообщения** пользователей (нативная расшифровка через Google Gemini 1.5 Flash).
*   **Мультиязычность:** Автоматически подстраивается под язык пользователя (RU/KZ).
*   **Удержание контекста:** Запоминает имя клиента и историю диалога для бесшовного общения.
*   **Эскалация:** Автоматически переводит диалог на живого оператора, если проблема критическая или клиент просит человека.

## 🛠 Технологический стек
*   **Язык:** Python 3.13+
*   **Фреймворк:** FastAPI (Асинхронная обработка)
*   **ИИ & Логика:** LangChain, Google Gemini API (`gemini-3.0-flash`), HuggingFace (`all-MiniLM-L6-v2` для эмбеддингов)
*   **База данных:** PostgreSQL 15 + расширение `pgvector`
*   **ORM & Миграции:** SQLAlchemy (asyncpg), Alembic
*   **Интеграция WhatsApp:** GreenAPI
*   **Инфраструктура:** Docker, Docker Compose

## 🚀 Установка и запуск (Для разработчиков)

### 1. Подготовка окружения
Убедитесь, что у вас установлены [Docker](https://docs.docker.com/get-docker/) и [Docker Compose](https://docs.docker.com/compose/install/).

Клонируйте репозиторий и создайте файл `.env` в корне проекта:
```bash
cp .env.example .env
```

Отредактируйте `.env` файл, добавив ваши ключи:
```ini
GREEN_API_INSTANCE_ID="12345678"
GREEN_API_TOKEN="green_api_token"

DB_USER=db_user
DB_PASSWORD=db_password
DB_HOST=db_host
DB_PORT=db_port
DB_NAME=qasqir
DATABASE_URL="postgresql+asyncpg://${DB_USER}:${DB_PASSWORD}@${DB_HOST}:${DB_PORT}/${DB_NAME}"

GEMINI_API_KEY="gemini_api_key"
GOOGLE_MODEL="gemini-2.5-flash"

GATEWAY_URL="http://gateway:8000"
CORE_URL="http://core:8001"
```

### 2. Запуск контейнеров
Запустите сборку и старт микросервисов (Core, Gateway, Postgres):
```bash
docker-compose -f docker-compose.yaml up -d --build
```

### 3. Инициализация Базы Данных (Миграции)
Примените миграции Alembic для создания таблиц и расширения `vector`:
```bash
docker-compose -f docker-compose.yaml exec core alembic upgrade head
```

### 4. Загрузка Базы Знаний (RAG)
Для того чтобы бот знал адреса станций и технические правила, выполните скрипт векторизации:
```bash
docker-compose -f docker-compose.dev.yaml exec core python scripts/ingest_data.py
```
*Скрипт прочитает файлы `location.csv` и `charger_type.txt` из папки `src/data/` и загрузит их в векторную БД.*

## 📖 Руководство по обновлению Базы Знаний

Архитектура бота позволяет обновлять его знания **без изменения программного кода**. 

### Обновление списка станций
1. Откройте файл `src/data/locations.csv`.
2. Добавьте новую станцию или измените существующую (соблюдайте формат разделителей).
3. Перезапустите скрипт загрузки (шаг 4 из инструкции по запуску). Старая база будет стерта, новая сгенерирована.

### Обновление технических инструкций
1. Откройте файл `src/data/charger_type.txt`.
2. Допишите новые правила (например, особенности зарядки новых марок авто).
3. Перезапустите скрипт загрузки `ingest_data.py`.

### Изменение статических правил (Тарифы, ссылки)
1. Откройте файл `src/bot/answers.py` (классы `TextRu` и `TextKz`).
2. Измените ссылки на приложения или правила оплаты. Изменения вступят в силу после перезапуска контейнера `core`.

## 📞 Обработка "Вызова оператора"
Бот запрограммирован самостоятельно пытаться решить проблему. Однако, если клиент прямо требует соединения с человеком, LLM сгенерирует в ответе скрытый тег `[CALL_MANAGER]`.
В файле `src/bot/logic.py` этот тег перехватывается, вырезается из финального сообщения клиенту, а система переводится в режим ожидания (в этом блоке разработчик может добавить логику отправки уведомлений в Telegram-канал техподдержки).
